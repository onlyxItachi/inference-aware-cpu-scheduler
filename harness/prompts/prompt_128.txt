Modern processors have abandoned the assumption that all cores are equal. A contemporary hybrid desktop or laptop processor combines a small number of wide, aggressively clocked performance cores with a larger number of narrow, efficient cores that occupy far less die area. The performance cores support simultaneous multithreading, so each physical core exposes two logical execution contexts that share the same functional units, the same level one cache, and the same level two cache.
