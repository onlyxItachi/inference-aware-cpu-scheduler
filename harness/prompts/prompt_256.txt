Modern processors have abandoned the assumption that all cores are equal. A contemporary hybrid desktop or laptop processor combines a small number of wide, aggressively clocked performance cores with a larger number of narrow, efficient cores that occupy far less die area. The performance cores support simultaneous multithreading, so each physical core exposes two logical execution contexts that share the same functional units, the same level one cache, and the same level two cache. The efficient cores do not support simultaneous multithreading at all, and instead are grouped into clusters of four that share a single level two cache among them. The memory hierarchy is therefore deeply asymmetric, and the cost of moving a running thread from one core to another depends entirely on which pair of cores is involved. Migrating a thread between the two logical contexts of a single physical core costs almost nothing, because no cache state is lost. Migrating between two physical performance cores costs more, because the level one and level two working sets must be rebuilt from the shared last level cache.
